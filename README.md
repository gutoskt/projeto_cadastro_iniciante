# 📝 Cadastro de Usuário

> Uma interface moderna e limpa de formulário web, criada para praticar a estruturação de dados, estilização e layouts responsivos.

---

## 📌 Sobre o Projeto

O projeto **Cadastro de Usuário** foi desenvolvido com o objetivo de exercitar a construção de formulários web bem organizados, funcionais e visualmente agradáveis. A proposta do layout divide a tela em duas partes principais: uma área interativa de formulário e um painel lateral dinâmico para destacar informações institucionais.

Com esta aplicação, pude aprofundar meu domínio sobre a semântica do HTML para inputs, alinhamento de componentes com CSS modernizado e adaptação da interface para garantir uma navegação intuitiva em qualquer dispositivo.

---

## ✨ Funcionalidades

- **Formulário Dinâmico:** Campos para inserção de dados (como e-mail e senha) com botões de ação intuitivos.
- **Layout Split-Screen:** Organização dividida entre a área de login/cadastro e a apresentação visual da marca.
- **Navegação Intuitiva:** Links e botões para transição entre acesso à conta e novos cadastros.
- **Design Responsivo:** A interface se adapta para oferecer uma boa experiência visual em dispositivos móveis, tablets e computadores.

---

## 🛠️ Tecnologias Utilizadas

Para a construção deste layout, utilizei as tecnologias essenciais do desenvolvimento web:

- **HTML5:** Estruturação semântica da página, formulários, labels e campos de entrada de texto.
- **CSS3:** Estilização visual, uso de **Flexbox** e **CSS Grid** para a divisão das colunas, alinhamento de elementos e responsividade.

## 🚀 Como Executar o Projeto

Como este projeto é estático e focado em frontend, você pode visualizá-lo diretamente no seu navegador, sem necessidade de dependências complexas.

### Passos:

```bash
# 1. Clone este repositório
$ git clone [https://github.com/gutoskt/projeto_cadastro_iniciante.git](https://github.com/gutoskt/projeto_cadastro_iniciante.git)

# 2. Acesse a pasta do projeto
$ cd projeto_cadastro_iniciante

# 3. Abra o arquivo index.html no seu navegador

```
Se estiver usando o **VS Code**, clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server**.
