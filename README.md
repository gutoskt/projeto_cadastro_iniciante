# 📝 Cadastro de Usuário

> Uma interface moderna e limpa de formulário web, criada para praticar a estruturação de dados, estilização e layouts responsivos.

---

## 📌 Sobre o Projeto

O projeto **Cadastro de Usuário** foi desenvolvido com o objetivo de exercitar a construção de formulários web bem organizados, funcionais e visualmente agradáveis[span_1](start_span)[span_1](end_span). A proposta do layout divide a tela em duas partes principais: uma área interativa de formulário e um painel lateral dinâmico para destacar informações institucionais[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span).

Com esta aplicação, pude aprofundar meu domínio sobre a semântica do HTML para inputs, alinhamento de componentes com CSS modernizado e adaptação da interface para garantir uma navegação intuitiva em qualquer dispositivo[span_4](start_span)[span_4](end_span).

---

## ✨ Funcionalidades

- **Formulário Dinâmico:** Campos para inserção de dados (como e-mail e senha) com botões de ação intuitivos[span_5](start_span)[span_5](end_span)[span_6](start_span)[span_6](end_span).
- **Layout Split-Screen:** Organização dividida entre a área de login/cadastro e a apresentação visual da marca[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span).
- **Navegação Intuitiva:** Links e botões para transição entre acesso à conta e novos cadastros[span_9](start_span)[span_9](end_span)[span_10](start_span)[span_10](end_span).
- **Design Responsivo:** A interface se adapta para oferecer uma boa experiência visual em dispositivos móveis, tablets e computadores[span_11](start_span)[span_11](end_span).

---

## 🛠️ Tecnologias Utilizadas

Para a construção deste layout, utilizei as tecnologias essenciais do desenvolvimento web[span_12](start_span)[span_12](end_span):

- **HTML5:** Estruturação semântica da página, formulários, labels e campos de entrada de texto[span_13](start_span)[span_13](end_span).
- **CSS3:** Estilização visual, uso de **Flexbox** e **CSS Grid** para a divisão das colunas, alinhamento de elementos e responsividade[span_14](start_span)[span_14](end_span).
